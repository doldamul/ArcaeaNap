개인정보처리방침

시행일: 2026년 5월 8일

1. 개요

본 개인정보처리방침은 ArcaeaNap이 데이터를 처리하는 방법을 설명합니다. ArcaeaNap은 Arcaea 플레이어를 위해 개발된 데스크톱 애플리케이션입니다.

2. 데이터 수집 및 사용

ArcaeaNap은 '로컬 중심' 애플리케이션입니다. Arcaea Online 인증 정보 및 API 토큰을 포함한 모든 민감한 정보는 귀하의 컴퓨터에 로컬로 저장됩니다. 당사는 귀하의 개인 데이터를 수집하는 중앙 서버를 운영하지 않습니다.

Google 사용자 데이터: 귀하가 Google 계정을 ArcaeaNap에 연결할 때, 애플리케이션은 계정 식별을 위한 이메일 주소(https://www.googleapis.com/auth/userinfo.email 및 openid 범위 사용) 및 Google Drive 내의 특정 파일(https://www.googleapis.com/auth/drive.file 범위 사용)에 접근하고 관리할 수 있는 권한을 요청합니다. 이 데이터는 귀하의 로컬 Arcaea 플레이 기록을 개인 Google 스프레드시트로 내보내고 동기화하는 목적에 한하여 사용됩니다. 또한, 로컬 곡 데이터베이스 생성을 위해 공용으로 유지 관리되는 Google 스프레드시트에 읽기 전용으로 접근(https://www.googleapis.com/auth/spreadsheets.readonly 범위 사용)하여 곡 정보를 가져옵니다.

3. 데이터 전송 및 공유

귀하의 데이터는 제3자와 공유되거나 판매되지 않습니다. 앱의 핵심 기능을 수행하는 데 필요한 경우에만 귀하의 로컬 기기에서 다음 공식 엔드포인트로 직접 전송됩니다.

  • 공식 Arcaea Online 서버 (플레이 기록 조회용)
  • Google API 엔드포인트 (개인 Google Sheets 데이터 직접 동기화 및 공용 곡 데이터 조회용)

4. 데이터 삭제 및 보관

사용자는 Google 계정 설정에서 앱의 액세스 권한을 언제든지 취소할 수 있습니다. 로컬에 저장된 정보는 사용자가 데이터 폴더를 직접 삭제함으로써 완전히 제거할 수 있습니다.

5. Google API 제한적 사용 정책 고지 (Limited Use Disclosure)

ArcaeaNap이 Google API로부터 수신한 정보를 사용하거나 다른 앱으로 전송하는 것은 제한적 사용(Limited Use) 요건을 포함하여 Google API 서비스 사용자 데이터 정책을 준수합니다.

6. 데이터 보안

애플리케이션이 전적으로 귀하의 로컬 기기에서 실행되므로, 데이터의 보안은 귀하의 로컬 시스템 보안에 달려 있습니다. ArcaeaNap은 가능한 경우 민감한 토큰에 대해 표준 OS 수준의 암호화를 사용합니다.

7. 제3자 서비스

ArcaeaNap은 lowiro의 Arcaea Online 및 Google Sheets와 통합됩니다. 데이터가 해당 서버에 도달한 후의 처리 방식에 대해서는 해당 서비스의 개인정보처리방침을 참조하십시오.

8. 문의

본 방침에 대한 문의사항은 arcaeanap@googlegroups.com 또는 GitHub Issues를 통해 전달주시기 바랍니다.
